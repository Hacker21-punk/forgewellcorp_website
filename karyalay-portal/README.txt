Karyalay Portal - prototype
===========================

How to open
-----------
Double-click index.html. It opens in Chrome, Edge, Firefox or Safari.
An internet connection is needed for the fonts and the Excel export library.

Sample logins
-------------
Super admin    super@portal.in   / super123
Company admin  admin@narmada.in  / admin123
Employee       sales@narmada.in  / user123

Good to know
------------
- All data and uploaded files are saved in the browser you open it in. They
  are not shared between computers or people.
- "Reset example data" on the sign-in page restores the sample records.
- Passwords in this prototype are for demonstration only and are not
  stored securely.
- Documents download as HTML. Open one and use Print > Save as PDF to make
  a PDF.

For live use by your team, this needs to be built as a hosted web
application with a database, secure logins and email/WhatsApp reminders.
This file is the approved blueprint for that build.
